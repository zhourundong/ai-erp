# AI原生ERP - 架构设计文档

## 一、项目概述

### 1.1 项目背景
AI原生ERP是一个技术演示/PoC项目，旨在探索AI技术与企业资源规划系统的深度融合，实现"AI自主执行+人工监督"的新型企业管理模式。

### 1.2 项目目标
- 构建AI驱动的采购供应链管理系统
- 实现自然语言交互界面
- 支持多AI模型可配置切换
- 预留未来扩展点（财务管理、生产管理等）

### 1.3 核心原则
1. **AI First**：AI是核心基础设施，而非外挂功能
2. **单体架构**：采用单体应用，降低复杂度，便于快速迭代
3. **可扩展性**：预留对接其他系统的扩展点
4. **可配置性**：AI模型、数据库等均可配置切换

### 3.1 采购供应链模块

#### 业务流程
```
需求申请 → AI智能分析 → 采购申请 → 供应商匹配 →
询价比价 → 采购订单 → 收货入库 → 发票校验 → 付款结算
```

#### 核心实体

```

│   采购申请       │     │   采购订单       │     │    供应商        │
├─────────────────┤     ├─────────────────┤     ├─────────────────┤
│ id              │     │ id              │     │ id              │
```

```java
/**

 */
public interface Skill {
    // Skill元信息
    String getName();           // 技能名称
    String getDescription();    // 技能描述
    SkillCategory getCategory();// 技能分类
    LoadStrategy getLoadStrategy(); // 加载策略

    // 工具定义
    List<ToolDefinition> getTools();

    // Prompt模板
    String getSystemPrompt();

    // 执行入口
    SkillResult execute(SkillContext context);
}

/**
 * Skill分类
 */
public enum SkillCategory {
    CORE,           // 核心技能 - 启动加载
    PROCUREMENT,    // 采购技能 - 按需加载
    FINANCE,        // 财务技能 - 按需加载
    INVENTORY,      // 库存技能 - 按需加载
    ANALYSIS        // 分析技能 - 按需加载
}

/**
 * 加载策略
 */
public enum LoadStrategy {
    EAGER,      // 启动时加载
    LAZY,       // 按需加载
    CACHED      // 加载后缓存，LRU淘汰
}
```

#### 4.2.2 流式对话接口 (SSE)

```yaml

参数: {
  message: string,      # 用户消息 (URL编码)
  sessionId?: string    # 会话ID
}
响应: Server-Sent Events (SSE)

事件类型:
- intent: 意图识别结果
- token: 文本片段 (逐步返回)
- tool: 工具调用信息
- result: 工具执行结果
- done: 对话完成
- error: 错误信息

示例:

event: token
data: {"content": "好的"}

event: token
data: {"content": "，我"}

event: token
data: {"content": "来帮您"}

event: tool
data: {"tool": "parseRequirement", "params": {...}}

event: result
data: {"result": {"materials": [...], "quantity": 100}}

event: token
data: {"content": "已创建采购申请..."}

event: done
data: {"processingTimeMs": 2500}
```
